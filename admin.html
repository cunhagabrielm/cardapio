QR Code do cardápio

Imprima e coloque nas mesas. Ao apontar a câmera, o cliente abre o cardápio em 3D.

Publicar o cardápio

Tudo que você cadastrou está salvo apenas neste navegador. Para os clientes verem, é preciso enviar os arquivos para o site.

Recomendado: baixe o pacote completo. Ele já vem com o cardapio.json, as fotos e os modelos 3D (.glb e .usdz) prontos — e com os modelos publicados a Realidade Aumentada funciona em todos os celulares.

Como publicar no GitHub Pages

  1. Descompacte o .zip baixado.
  2. Copie as pastas dados/, fotos/ e modelos/ por cima das do seu projeto.
  3. No GitHub: Add file → Upload files, arraste as pastas e clique em Commit changes.
  4. Espere cerca de 1 minuto e recarregue o site com Ctrl+F5.
